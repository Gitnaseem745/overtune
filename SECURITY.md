# Security Policy

## Supported Versions

We release patches for security vulnerabilities on the latest active version.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

The Overtone team and maintainers take security issues seriously. If you believe you have found a security vulnerability in Overtone:

1. **Please do NOT report security vulnerabilities through public GitHub issues.**
2. Instead, report it privately through GitHub's [Security Advisory feature](https://github.com/gitnaseem745/overtune/security/advisories/new) or by reaching out directly to the author **Naseem Ansari** ([@gitnaseem745](https://github.com/gitnaseem745)).
3. Please include:
   - Type of issue (e.g., IPC boundary bypass, arbitrary file read, buffer overflow)
   - Full paths and source code references
   - Proof-of-concept steps to reproduce
   - Potential impact of the vulnerability

### Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Assessment & Triage**: Within 5 business days.
- **Fix & Disclosure**: We will collaborate with you to create a patch and coordinate public release timeline.

Thank you for helping keep Overtone safe for all users!
